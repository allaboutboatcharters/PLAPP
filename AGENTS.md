# AGENTS.md — PLAPP (Crew & Passenger List PWA)

Инструкции для ИИ-агентов, работающих над этим проектом.

## В начале КАЖДОЙ сессии

**Первым делом прочитай `handoff.md`** в корне проекта (`PLAPP/handoff.md`).
Это точка входа: там записано, на чём остановились в прошлую сессию — текущее
состояние, что сделано, что в работе, следующие шаги и открытые вопросы.
Если файла нет — значит сессий ещё не было, начинай с `PLAN.md`.

После `handoff.md` при необходимости сверься с:
- `PLAN.md` — полный план, архитектура, согласованные решения, спецификация XLSX
  и промпта распознавания.
- `README.md` — как запускать, тестировать и деплоить.

## В конце сессии

Когда пользователь говорит **«заканчиваем сессию»**, сработает скилл
`session-handoff`: он **перезаписывает** `handoff.md` актуальным состоянием.
`handoff.md` НЕ хранит историю — только снимок «где мы сейчас».

## Ключевые факты о проекте

- Стек: Vite + Vue 3 (`<script setup>`) + TypeScript, vue-router, Pinia,
  Dexie (IndexedDB), ExcelJS, vite-plugin-pwa. Фреймворк — Vue 3, НЕ React.
- Данные хранятся только на устройстве. Бэкенда и своего домена нет.
- Claude API вызывается напрямую из браузера (модель `claude-sonnet-5`,
  структурный вывод через `tool_use`). Ключ — в настройках (IndexedDB); в dev
  подставляется из `.env` (`VITE_CLAUDE_API_KEY`), в production в сборку не идёт.
- Имя генерируемого файла — всегда `Crew and Passenger List.xlsx`.
- XLSX строится строго по образцу — при правках модуля
  `src/lib/passengerListWorkbook.ts` сверяй результат дампом openpyxl с эталоном.
- Сканы паспортов самоудаляются через 72 ч; готовые списки хранятся бессрочно.

## Правила

- `.env` — в `.gitignore`, НИКОГДА не коммить (там API-ключ).
- Перед коммитом: `npm run build` (vue-tsc + сборка) должен проходить.
- Коммить осмысленными этапами; язык сообщений — русский.
